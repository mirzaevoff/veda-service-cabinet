# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

Правило: изменения копятся в `[Unreleased]`; при бампе версии (`pnpm version ...`, только по команде) секция переименовывается в номер версии с датой.

## [Unreleased]

### Added

- Юрлица: поле «ПИНФЛ» (физлица/ИП) — приходит из автозаполнения по ИНН (Didox `personalNum`, API 0.29), редактируется в форме и показывается в шапке карточки/реквизитах
- Страница юрлица: блок «Заведения» — привязанные к этому ЮЛ точки/сети из iiko (название, тип, UID, город, статус) с ссылкой в раздел; красивая заглушка, если ничего не привязано (API 0.29, фильтр `legalEntityId`)

### Changed

- Страница юрлица: убран блок «Заведение» (устаревшее текстовое поле) — заведения ведёт таблица «Заведения» (привязки из iiko); поле «Заведение» также убрано из создания/правки (API 0.29 его игнорирует)
- Справочник юрлиц: убрана колонка «Заведение» — таблица помещается без горизонтального скролла; длинные «Название» и «Директор» обрезаются с аккуратной подсказкой при наведении; кнопка «Добавить Юр. лицо»
- Привязка ЮЛ к заведению: список юрлиц ограничен по высоте (~5 строк) с прокруткой, чтобы карточка не удлинялась

## [0.21.1] - 2026-08-12

### Changed

- Карточка iiko в детали заведения разложена на блоки с разделителями: идентификаторы (UID, ID клиента и версия — моноширинными чипами, UID с копированием) и статус сервера; о заведении (формат приглушённым, адрес компактно под меткой); контакты; данные по iiko приглушённо — вместо сплошного списка белым

## [0.21.0] - 2026-08-12

### Added

- Дашборд стал живым (API 0.26, `GET /dashboard`): карточки-ссылки «Серверы клиентов» (в сети/недоступны), «Заведения» (работают/не работают/временно, привязки к ЮЛ), «Обращения» (открытые, не взятые, просроченный SLA) и «Пользователи» (онлайн сейчас/всего) — каждая видна только при своём праве; для пользователей без блоков осталась заглушка «В разработке»

### Changed

- Настройки: каждая группа — одна компактная карточка с продуманной сеткой и общей кнопкой «Сохранить» (Организация: ИНН|Наименование / Адрес / МФО|Банк|Счёт / Директор / Телефон|Почта; портал iiko: URL + логин|пароль; Капиталбанк: два URL в строку)
- Карточка заведения оформлена секциями с иконками: «Статус», «Юр. лицо» (переименовано с «Наше юрлицо»), «Карточка iiko»; UID копируется в один клик
- Страница юрлица: блок «Участники» переименован в «Пользователи», приглашение вынесено в модалку (телефон + роль), у пустого списка — дружелюбная заглушка с иконкой

## [0.20.0] - 2026-08-11

### Added

### Changed

- Обращения: у поддержки (`tickets.manage`) скрыта кнопка «Новое обращение» — поддержка отвечает на обращения, а не создаёт их (API 0.25.1, ER413); на всякий случай ошибка обрабатывается и в мастере создания
- Выпадающие списки открываются аккуратным списком под полем — без наложения выбранного пункта поверх (особенно было заметно в модалке фильтров)
- Тексты: колонка «Наше ЮЛ» → «Юр. лицо» в «Заведениях», «Виден» → «Последняя активность» в «Заведениях» и «Серверах клиентов»

## [0.15.0] - 2026-08-11

### Added

- Раздел «Банк» (API 0.21, права `bank.view`/`bank.manage`) в «Администрировании»:
  - Транзакции: суммы из тийинов в сумах, направление поступление/списание, метка «Между своими», поиск, фильтры в модалке (счёт, направление, период) и сортировка (дата/сумма), деталь в шторке с реквизитами сторон и обновлением карточки из банка
  - Счета: карточки со снапшотом (остаток, доступно, обороты дня), ручной синк, вкл/выкл отслеживания, добавление (МФО+номер иммутабельны) и удаление с обработкой ER1206; ошибка последнего синка на карточке
  - Сверка: журнал ночных сверок (сошлось/расхождение/день не закрыт), количество документов и суммы мы/банк, ручная сверка любой даты
- Виджет «Курсы Капиталбанка» на дашборде (право `bank.view`): ЦБ/покупка/продажа c дельтами, флаг устаревших данных
- Настройки: группировка по секциям (Валюта, Капиталбанк, Организация) и автозаполнение реквизитов организации по ИНН из Didox (телефон/почта — вручную)
- Юрлица: поле «Банк» — заполняется лукапом из собственного справочника банков по МФО, редактируется в форме, показывается в реквизитах
- Сортировка в списках: кликабельные заголовки колонок (три состояния — по возрастанию, по убыванию, сброс к дефолту) в «Пользователях», «Продуктах», «Юр. лицах» и обеих таблицах статистики чеклистов; селект сортировки для карточных списков — «Обращения» (дедлайн SLA, активность, дата, статус) и «Задания» чеклистов
- Поиск в «Обращениях» (по теме и автору — имя/телефон), состояние живёт в URL вместе с фильтрами и сортировкой
- Фильтры продуктов, которых не хватало: валюта, активность, диапазон цены в сумах

### Changed

- Фильтры вынесены в модалку «Фильтры» с числом активных и чипами под шапкой (клик по чипу снимает фильтр) — в «Обращениях» (было 7 контролов в две строки), «Пользователях» и «Продуктах»; снаружи остались поиск, вкладки и сортировка
- Списки чеклистов упорядочены осмысленно: шаблоны по названию, расписания по ближайшему запуску; роли — по названию
