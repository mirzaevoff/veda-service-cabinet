# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

Правило: изменения копятся в `[Unreleased]`; при бампе версии (`pnpm version ...`, только по команде) секция переименовывается в номер версии с датой.

## [0.39.0] - 2026-09-02

### Changed

- Навигация: **сворачиваемые группы** в сайдбаре (клик по заголовку группы сворачивает/разворачивает, состояние запоминается; группа с активной страницей всегда раскрыта) — компактнее при большом числе пунктов
- Навигация: **командная палитра ⌘K / Ctrl+K** (иконка поиска в шапке) — быстрый переход по разделам с фильтрацией и клавиатурой

## [0.38.0] - 2026-09-02

### Added

- Обращения: при закрытии **просроченной по SLA** заявки сотрудником (не автором) теперь запрашивается обязательная **причина нарушения SLA** — вписывается в диалоге закрытия и уходит в `slaBreachReason` (API ER414); причина и `closedBy` попадают в дашборд тех-отдела

## [0.37.0] - 2026-09-02

### Added

- **Дашборд тех-отдела** (Тех. поддержка → Статистика, API 0.42) — сводная статистика заявок (всего/новых/в работе/закрыто, ср. первый ответ и обработка, нарушения и % соблюдения SLA) и таблица по сотрудникам (принято/закрыто/активные, время первого ответа/обработки/общее, нарушения и % SLA, средняя оценка) с сортировкой по любому показателю; фильтр периода день/неделя/месяц/произвольный; детализация — клик по «закрыто»/«нарушения SLA» открывает отфильтрованный список заявок (по сотруднику и периоду). Право `tickets.list`

## [0.36.0] - 2026-09-02

### Added

- **База знаний** (Тех. поддержка → База знаний, API 0.42) — статьи (типовые ошибки, шаблоны, регламенты) в Markdown: список с поиском и фильтром по тегам, просмотр с рендером GFM-markdown (заголовки, списки, таблицы, код, цитаты, ссылки) и вложениями, редактор с тегами и живым предпросмотром, создание/правка/удаление. Права `knowledge.view` / `knowledge.manage`. Пункт «База знаний» в навигации активирован (был заглушкой)

## [0.35.0] - 2026-09-02

### Added

- **Инвентаризация** (Тех. поддержка → Инвентаризация, API 0.42) — акты инвентаризации оборудования: создание акта-снимка по офису/отделу, сверка каждой позиции («не проверено / на месте / отсутствует» + фактические статус, отдел, ответственный, заметка), автоматическая пометка расхождений и сводка (всего/проверено/на месте/отсутствует/расхождения), статусы черновик→завершён→утверждён, **электронное утверждение** (блокирует акт от изменений). Права `inventory.view` / `inventory.manage` / `inventory.approve`

## [0.34.0] - 2026-09-02

### Added

- **Оборудование** (Тех. поддержка → Оборудование, API 0.42) — реестр оборудования офисов: таблица с поиском и фильтрами (офис/категория/статус), карточка (наименование, серийный/инвентарный №, офис/отдел, категория, статус, ответственный, заметка), создание/правка/удаление. Права `equipment.view` / `equipment.manage`
- **Справочники → Локации** — офисы и отделы внутри них (создание/переименование/удаление), права `locations.view` / `locations.manage`
- **Справочники → Оборудование** — категории и статусы оборудования (со статусом по умолчанию), права `equipment.view` / `equipment.manage`

## [0.30.0] - 2026-08-25

### Added

- Счета на оплату: **фильтр по месяцу при генерации** — в диалоге поле «Месяц (необязательно)» (`period=YYYY-MM`, API 0.35); предпросмотр пересчитывается при смене месяца, без месяца — все неоплаченные разом

### Changed

- iiko-счета: статус в таблице и карточке берётся из **`effectiveStatus`** (API 0.35) — аннулированные (нет в процессинге) показываются как «Cancelled» и исключены из сводки

## [0.29.0] - 2026-08-25

Права `invoices.view` / `invoices.manage`, обработка ER1600–ER1602

- Авторизация по номеру телефона (passwordless, api.vedavector.com): вход, регистрация (имя), подтверждение 6-значным SMS-кодом — единый мастер на `/login` с шагами телефон → имя → код
- Компоненты: маска телефона `+998 XX XXX XX XX`, OTP-ячейки по гайду (активная с акцентной рамкой, ошибка с тряской), таймер повторной отправки
- Обработка ошибок API по кодам ER2xx (тексты на ru/uz/en), сетевых ошибок
- Сессия: access/refresh-токены в cookies, ротация refresh с мьютексом, выход с отзывом токена
- Защита маршрутов в `src/proxy.ts`: без токена — на `/login`, с токеном `/login` недоступен
- Шапка на главной: имя пользователя (`GET /users/me`) и кнопка «Выйти»

## [0.1.0] - 2026-08-04

### Added

- Скелет проекта: Next.js 16 + TypeScript, Tailwind v4, shadcn/ui (base-nova)
- Мультиязычность next-intl: ru (дефолт) / en / uz, роутинг `/[locale]`
- Тёмная/светлая тема (next-themes, по системной)
- Фирменный стиль Veda Service (STYLEGUIDE.md, единый с мобильным приложением): белый фон, красный `#A21500` как единственный акцент, Inter + Unbounded (только бренд), pill-кнопки
- Стартовая страница — вордмарк «Veda Service»
- Прод-инфраструктура: Docker (standalone-сборка, порт 4900), GitHub Actions деплой по пушу в `production` (lint → SSH → `docker compose up -d --build`)
