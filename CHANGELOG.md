# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

Правило: изменения копятся в `[Unreleased]`; при бампе версии (`pnpm version ...`, только по команде) секция переименовывается в номер версии с датой.

## [Unreleased]

### Fixed

- Тосты-уведомления теперь реально показываются (успешное сохранение, ошибки, «рассылка отправлена» и т.д.) — контейнер уведомлений не был смонтирован с самого начала

## [0.7.0] - 2026-08-04

### Added

- Роли: локализованные названия `{ru, en, uz}` — в списке ролей, бейджах пользователей и меню; форма роли с идентификатором (slug) и названием на трёх языках
- Рассылка: загрузка картинки в один клик (публичный файл с абсолютным URL — работает и для push)

- Кастомный дейт-пикер (календарь с выбором месяца/года, локализация ru/uz/en) вместо браузерного
- Лимиты символов: тема обращения — 50, описание и сообщения чата — 2000 (синхронно с API)

### Changed

- **Breaking-совместимость с API 0.10**: поле `name` ролей заменено на `slug` + `title`

- Навигация: «Дашборд», секция «Основное» (Поддержка) и «Администрирование»
- Выпадающие списки: аккуратные отступы пунктов и галочка выбора; меню действий больше не обрезается по ширине иконки

### Fixed

- Пустые бейджи ролей в списке пользователей (API перестал отдавать role.name в списке — имя подставляется из справочника ролей)

## [0.6.0] - 2026-08-04

### Added

- Профиль: фамилия и дата рождения (частичный `PATCH /users/me`); фамилия показывается в админ-списке пользователей и меню

### Changed

- Плавные переходы между страницами: скелетоны показываются только при загрузке дольше 250 мс, списки кэшируются на время сессии, стабилизирован скроллбар (без сдвига контента)
- Категории: компактные строки со сворачиванием подкатегорий (счётчик, chevron)
- Навигация: плотнее расстояния между пунктами

## [0.5.0] - 2026-08-04

### Added

- Админ-раздел: пользователи (таблица с поиском/фильтрами, смена роли, блокировка с завершением сессий), роли (CRUD с чекбоксами прав по группам, защиты системных), категории тикетов (дерево, CRUD на трёх языках, порядок, вкл/выкл)
- Уведомления: колокольчик с лентой (markdown-ссылки, картинки, кнопки), «прочитать все», страница рассылки (broadcast или выбранным, право `notifications.send`)
- Профиль: смена имени, смена номера через SMS-код, список активных сессий с устройствами, завершение сессии и «выйти со всех устройств»
- Непрочитанные сообщения: бейджи в списке тикетов и в навигации, автоматическая пометка прочитанным в чате
- Страницы ошибок: фирменные 404 и error boundary; статические `public/errors/{50x,4xx}.html` для nginx (когда приложение лежит)

### Changed

- Актуализация под API 0.8.0: локализованные категории `{ru, en, uz}`, `GET /roles` как страница, единый стандарт списков
- Починен бесконечный перезапрос `/users/me` (нестабильный useRouter в зависимостях эффектов)

## [0.4.0] - 2026-08-04

### Added

- Каркас панели: sidebar с навигацией (collapse, мобильное Sheet-меню), шапка с заголовком раздела и меню пользователя, страница «Дашборд» (заглушка «В разработке»)
- Тикеты (`/tickets`): список с фильтрами по статусу/категории и серверной пагинацией; для staff (`tickets.list`) — вкладки «Мои/Все»
- Создание обращения (`/tickets/new`): мастер категория → субкатегория → тема/описание, вложения (до 10, прогресс, повтор при ошибке)
- Чат обращения (`/tickets/[id]`): реалтайм по Socket.IO (комнаты, ре-join после разрыва, дозагрузка пропущенного), optimistic-отправка с повтором, пагинация истории вверх, дата-разделители, typing-индикатор, лайтбокс изображений, video/audio-плееры, PDF-карточки
- Управление тикетом: закрытие автором (confirm), для `tickets.manage` — «Взять в работу» и переоткрытие
- Прокси файлов `/api/files/[id]` с Bearer из cookie и пробросом Range
- Провайдер текущего пользователя с правами (`can()`), авто-refresh access-токена во всех авторизованных запросах и в сокете

## [0.3.0] - 2026-08-04

### Added

- Переключатель языка (ru / uz / en) на страницах входа и главной
- Футер: версия кабинета (package.json) + версия API (`GET /`) и копирайт Veda Vector LLC

### Fixed

- Деплои в production больше не выполняются параллельно (concurrency group в GitHub Actions — гонка ломала пересоздание Docker-контейнера)

## [0.2.0] - 2026-08-04

### Added

- Авторизация по номеру телефона (passwordless, api.vedavector.com): вход, регистрация (имя), подтверждение 6-значным SMS-кодом — единый мастер на `/login` с шагами телефон → имя → код
- Компоненты: маска телефона `+998 XX XXX XX XX`, OTP-ячейки по гайду (активная с акцентной рамкой, ошибка с тряской), таймер повторной отправки
- Обработка ошибок API по кодам ER2xx (тексты на ru/uz/en), сетевых ошибок
- Сессия: access/refresh-токены в cookies, ротация refresh с мьютексом, выход с отзывом токена
- Защита маршрутов в `src/proxy.ts`: без токена — на `/login`, с токеном `/login` недоступен
- Шапка на главной: имя пользователя (`GET /users/me`) и кнопка «Выйти»

## [0.1.0] - 2026-08-04

### Added

- Скелет проекта: Next.js 16 + TypeScript, Tailwind v4, shadcn/ui (base-nova)
- Мультиязычность next-intl: ru (дефолт) / en / uz, роутинг `/[locale]`
- Тёмная/светлая тема (next-themes, по системной)
- Фирменный стиль Veda Service (STYLEGUIDE.md, единый с мобильным приложением): белый фон, красный `#A21500` как единственный акцент, Inter + Unbounded (только бренд), pill-кнопки
- Стартовая страница — вордмарк «Veda Service»
- Прод-инфраструктура: Docker (standalone-сборка, порт 4900), GitHub Actions деплой по пушу в `production` (lint → SSH → `docker compose up -d --build`)
